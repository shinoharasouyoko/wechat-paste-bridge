# 文章包

```text
article-package/
  draft.json
  article.html
  wechat.html
  xiumi.html
  cover.png
  images/
```

`draft.json` 需要 `title`、`content_html`、`cover`。`wechat_html` 和 `xiumi_html` 可指向两个适配版本；若省略，软件使用母稿。封面及图片必须在包内，正文使用相对路径。

正文、标题、说明、价格和联系方式使用文本元素；照片和装饰可以是图片。让图片的布局尽量简单，以内联样式表达排版。示例图文见仓库 `examples/weekend-city`。

图片组合在目标编辑器中可能被拆开。若合并为单张图片可减少这种风险，要保留周围文字为可编辑文字，并说明合并后的照片不能单张编辑。连续底图、层叠、横栏和 GIF 的兼容性应由实际目标编辑器决定。不要把浏览器预览视为微信或秀米的最终结果。

复制软件只负责本地复制并打开网页，不自动创建、发布或群发公众号文章。截图与案例仅在用户允许且素材适合对外展示时使用，上传仓库前移除账户、客户和个人信息。
